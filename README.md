### Ce dépot est consacré à un projet informatique de première année à l'ENSTA campus de Brest.

##### Prérequis

- Python 3.10+ installé sur votre machine

---
### Lancement
##### Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install PyQt5
python3 main.py
```

##### Windows

```cmd
python -m venv venv
venv\Scripts\activate
pip install PyQt5
python main.py
```
